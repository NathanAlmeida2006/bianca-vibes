BIANCA ANDRADE — DESIGN PORTFOLIO

ABRIR
1. Extraia o ZIP.
2. Abra a pasta portfolio_site.
3. Dê dois cliques em index.html.

SERVIDOR LOCAL (opcional)
Abra o terminal nesta pasta e execute: python -m http.server 8000
Acesse http://localhost:8000

GITHUB PAGES
Envie todo o conteúdo desta pasta para a raiz de um repositório. Em Settings > Pages, selecione Deploy from a branch, branch main e /(root).

NETLIFY
Arraste a pasta portfolio_site para a área de deploy manual em app.netlify.com.

EDITAR
index.html = textos e projetos; styles.css = visual; script.js = interações; assets/ = imagens.
